# 🏧 ATM Management System (C++)

A simple, menu-driven ATM simulation developed using **C++ and Object-Oriented Programming (OOP)**. It allows multiple users to securely access basic banking operations using account numbers and PIN authentication.

## ✨ Features

- PIN-based user authentication
- Multiple user accounts
- Check account balance
- Deposit and withdraw money
- Create new bank accounts
- File handling for permanent data storage
- Automatic balance updates after transactions

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming
- File Handling (`ifstream`, `ofstream`)
- STL Vector

## 📂 Project Structure

```text
ATM-Management-System/
```

## ▶️ How to Run

Compile the program:

```bash
g++ ATM.cpp -o ATM
```

Run the program:

```bash
./ATM
```

On Windows:

```powershell
.\ATM.exe
```
